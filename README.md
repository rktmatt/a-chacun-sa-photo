# À chacun sa photo

À chacun sa photo is a desktop application for sorting class photographs for families. It has no cloud service, account, telemetry, updater, or remote runtime dependency.

## What the first version does

- encrypts the roster of pupils at rest with SQLCipher;
- imports JPEG, PNG and HEIC photos into memory for the current working session;
- converts HEIC locally to JPEG when it is imported;
- lets the teacher draw and assign face ellipses manually;
- exports one JPEG folder per pupil;
- blurs the face ellipse of pupils whose parent/guardian has not authorised distribution, except in that pupil's own folder;
- re-encodes every export as JPEG, removing image metadata such as GPS;
- clears the working session without retaining a copy of the photos.

Photos are never copied to application storage. They exist in browser memory for the open session and, at export, are re-encoded one at a time and written directly into the folder selected by the teacher.

## Privacy model

The only persistent data is `roster.sqlite` in the platform-specific local application-data directory. It is opened with SQLCipher using a random encryption key generated by the app and retained in the operating system's protected credential vault. The teacher does not have to create, remember, or enter a secret.

The parental setting is deliberately conservative: a pupil is **masked for other families** unless the teacher records an authorisation. The app assists with distribution choices; it does not replace the school’s written authorisation process.

## Offline guarantee

Production content-security policy does not permit remote scripts, images, forms, or network connections. The app includes no telemetry or update mechanism. The Windows installer is configured to embed the WebView2 offline installer.

Release verification must be performed with outbound network disabled and should assert that neither the app process nor its webview makes a connection attempt.

## Development

Requirements: a current Node.js release, Rust, and the platform prerequisites for Tauri.

```sh
npm install
npm run tauri dev
```

Build the frontend with `npm run build`. Build a release installer with `npm run tauri build` on each target platform.

## Before a public pilot

- complete the RGAA accessibility audit;
- test the exact export/blur rule with teachers and a DPO;
- add a formal roster backup/restore process that remains encrypted;
- establish signed releases, reproducible builds, and a network-denied release test;
- test HEIC conversion against representative iPhone photos and lower-memory Windows devices.
