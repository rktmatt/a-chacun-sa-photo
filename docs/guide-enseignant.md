# Guide de l’enseignant

## 1. Ouvrir sa classe

Au premier lancement, cliquez sur **Ouvrir ma classe**. La liste de vos élèves est protégée automatiquement par
l’ordinateur : vous n’avez aucun mot de passe à retenir.

Sur certains ordinateurs (souvent sous Linux), l’application vous demande de **choisir une phrase de passe**. Elle sert
de clé pour protéger la liste des élèves ; elle vous sera redemandée à chaque ouverture. Notez-la en lieu sûr : si vous
l’oubliez, il faudra ressaisir la classe (vos photos ne sont pas concernées).

## 2. Saisir les élèves

- Tapez le prénom et le nom, puis **Ajouter l’élève**.
- Cochez **Diffusion autorisée par la famille** seulement si vous avez l’autorisation écrite. Sans cette case, le visage
  de l’enfant sera flouté dans les dossiers des autres élèves (jamais dans le sien).
- Pour gagner du temps : **Gérer la classe › Importer une liste** accepte un fichier texte (un nom par ligne) ou un
  export de tableur / ONDE avec des colonnes « Nom » et « Prénom ». Les élèves importés sont masqués par défaut : cochez
  ensuite les accords un par un avec le bouton ✎.
- Le bouton ✎ à côté d’un élève permet de corriger son nom, changer l’accord (une famille peut changer d’avis) ou le
  supprimer.

## 3. Identifier les enfants sur les photos

1. **Ajouter des photos** : choisissez les photos de la sortie ou du spectacle. Elles ne sont pas copiées : l’application
   les garde en mémoire jusqu’à l’export ou jusqu’à sa fermeture.
2. Cliquez sur un élève dans la liste, puis **dessinez un cadre** autour de son visage sur la photo.
3. Faites de même pour chaque enfant visible. Pour un enfant qui n’est pas dans votre classe, ou un visage à ne jamais
   montrer, utilisez **Visage inconnu** : il sera flouté dans tous les dossiers.
4. Passez à la photo suivante avec les flèches ‹ › ou les touches ← →.

Astuces :

- **Zoom** : boutons − / + au-dessus de la photo, touches `+` `-` `0` (quand la photo a le focus), ou Ctrl + molette. Utile pour les photos de groupe.
- **Agrandir le texte** de toute l’application : Ctrl + `=` (⌘ + `=` sur Mac), Ctrl + `-` pour réduire, Ctrl + `0` pour revenir à la taille normale.
- Un cadre se déplace en le faisant glisser et se redimensionne par ses coins. Le × le retire ; le ⇄ l’attribue à
  l’élève sélectionné (en cas d’erreur).
- **Au clavier** : choisissez l’élève, allez sur la photo avec Tab, appuyez sur Entrée pour créer un cadre au centre ;
  flèches pour le déplacer, Maj + flèches pour le redimensionner, Suppr pour le retirer.
- **Sur Mac, au clavier seul** : pour que Tab passe aussi sur les boutons, activez « Navigation au clavier » dans
  Réglages Système > Clavier (sinon, utilisez Option + Tab).

> **Important** : l’application ne reconnaît pas les visages. Un enfant non autorisé que vous n’avez pas encadré, par
> exemple au second plan, apparaîtra net chez les autres familles. Vérifiez chaque photo.

## 4. Exporter

1. Choisissez le type de masquage : **flou** ou **aplat opaque** (plus sûr sur les gros plans).
2. **Exporter par élève**, relisez le récapitulatif, puis choisissez où créer le dossier.
3. L’application crée un nouveau dossier « Photos du JJ-MM-AAAA à HHhMM » contenant un sous-dossier par élève. Elle
   n’écrase jamais un export précédent.

Les photos exportées ne contiennent plus de métadonnées (date, appareil, position GPS).

Une fois les photos remises aux familles (par l’ENT, une clé USB…), **supprimez le dossier d’export** de l’ordinateur.

## 5. Terminer

- **Effacer la session** retire les photos de l’application (les fichiers d’origine ne sont pas touchés).
- Si vous fermez l’application avant d’avoir exporté, elle vous prévient.

## 6. Changer d’ordinateur, fin d’année

- **Gérer la classe › Sauvegarder** : crée un fichier de sauvegarde chiffré avec une phrase de passe que vous choisissez.
  Sur l’autre ordinateur, **Restaurer** avec la même phrase de passe.
- **Gérer la classe › Nouvelle année : effacer la classe** : supprime tous les élèves et leurs accords. À faire en fin
  d’année scolaire.
