# Kit RGPD

Documents pour aider l’école à encadrer l’usage d’« À chacun sa photo ». Ce sont des **modèles à adapter et à faire
valider par le délégué à la protection des données (DPO) de votre académie**, qui reste l’interlocuteur de référence.
Ils ne constituent pas un avis juridique.

| Document | Pour qui | Usage |
|---|---|---|
| [fiche-registre.md](fiche-registre.md) | Directeur / directrice, DPO | Décrire le traitement pour le registre des activités de traitement |
| [modele-autorisation.md](modele-autorisation.md) | Familles | Recueillir l’accord de diffusion des photos aux autres familles de la classe |
| [note-dpo.md](note-dpo.md) | DPO, référent numérique | Description technique : données, stockage, sécurité, risques |

Rappel : dans une école publique du premier degré, le responsable de traitement est en principe l’IA-DASEN ; dans un
établissement du second degré, le chef d’établissement. Vérifiez la situation de votre école avec votre DPO.
